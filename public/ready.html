Qué significa cada estado. Listo: puede recibir tráfico. Degradado: sigue recibiendo tráfico, pero algo no crítico está caído — sin Redis se pierden cachés e idempotencia, sin el worker de Go fallan las operaciones masivas, y el resto de la API responde. No listo: falla MySQL o Mongo, así que el servidor devuelve 503 y un balanceador debería sacarlo de rotación.
Esto no es /health. Ese responde mientras el proceso atienda un socket y sirve para decidir reiniciar o no. Esta página lee /ready, que sí consulta las dependencias y sirve para decidir mandarle tráfico o no.
El servidor cachea 2 s. Pedirlo en bucle no multiplica la carga sobre la base de datos; por eso puede aparecer cached. Marca «forzar» para saltarla.
